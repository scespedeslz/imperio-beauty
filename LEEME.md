# Página de "Construí tu imperio beauty" · by SamCe

## Antes de subirla
1. Creá en Mercado Pago un link de pago de $11.900 (cuotas: hasta 2, medios: tarjeta y otros).
2. En `index.html` buscá `[LINK DE PAGO]` y pegá tu link en su lugar.
3. El PDF completo NO va acá: se lo mandás por mail a quien compre.

## Subirla
- GitHub: creá un repo nuevo (ej. `imperio-beauty`), "uploading an existing file", arrastrá todo lo de esta carpeta y Commit changes.
- Vercel: Add New → Project → Import el repo → Deploy.
